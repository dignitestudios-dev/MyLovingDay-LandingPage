# MyLovingDay - Landing Page

Next.js landing page clone for **My Loving Day** — Where Every Memory Finds a Safe Home.

## Tech Stack
- Next.js (App Router)
- React
- TypeScript
- Lucide React

## Getting Started

First, install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
